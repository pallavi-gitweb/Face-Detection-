
## Face Detection and Counting System

## Project Description

Face Detection and Counting System is a computer vision project developed using Python and OpenCV. It detects human faces in images, identifies their locations, and calculates the total number of faces detected.
Manually counting faces in images containing multiple people can be time-consuming. This project automates the process by using the Haar Cascade Classifier to detect faces and draw bounding boxes around them.

## Features

- Detect human faces in images.
- Count the total number of detected faces.
- Draw rectangular boxes around detected faces.
- Display the processed image with face detection results.

## Technologies Used

- Python – Programming language
- OpenCV – Image processing and face detection
- Haar Cascade Classifier – Face detection algorithm
- Google Colab – Development and execution environment

## How It Works

1. Load an input image.
2. Convert the image into grayscale.
3. Apply the Haar Cascade Classifier to detect faces.
4. Draw rectangles around the detected faces.
5. Display the image and print the total face count.

## Future Enhancements

- Live webcam face detection and counting.
- Save detection results to CSV or Excel files.
- Generate detection reports with timestamps.
- Improve detection performance under different lighting conditions.

## Project Status

The image-based face detection and counting functionality has been tested. Live webcam detection and additional reporting features are planned enhancements.
